## Bring Your Own Key (BYOK)

AgentOne supports using your own API keys for direct access to each provider. When you add your own key, requests go directly from your device to the provider — AgentOne never sees your traffic.

To add an API key:

1. Open **Settings → Providers**
2. Select the provider you want to configure
3. Enter your API key

<Callout>
  API keys are stored locally on your device. When cross-device sync is enabled,
  keys are encrypted before syncing.
</Callout>
