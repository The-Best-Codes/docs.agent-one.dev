AgentOne can be used entirely without an account. Creating a free account unlocks additional features.

## What You Get with an Account

- **Cross-device sync** for chats, settings, and encrypted API keys
- **Access to AgentOne's built-in AI models** — no API key needed

Create your account at [agent-one.dev](https://agent-one.dev).

## Authentication

Sign-in is handled through the AgentOne website. When you authenticate, the app uses deep links (`agent-one://` protocol) to securely pass your session back to the desktop app.

<Callout>
  No account is required to use AgentOne with your own API keys. An account is
  only needed for cross-device sync and access to built-in AgentOne models.
</Callout>
