AgentOne is an AI agent desktop app built with Tauri and React. It's not a chatbot — it takes a goal, breaks it into steps, uses tools and connected apps, and works through each step on its own. It runs as a native desktop application with full system access and offline support.

## Key Features

- **600+ AI models** from 20+ providers including OpenAI, Anthropic, Google, xAI, Mistral, Groq, Cerebras, and more
- **2,000+ extensions** connecting to apps like Gmail, Notion, Slack, GitHub, Google Calendar, and more
- **Parallel agent execution** — multiple agents work on different parts of a task simultaneously
- **MCP server support** — extend AgentOne with Model Context Protocol servers
- **Built-in tools** — web search, URL content fetching, date/time, and more
- **Private by default** — your data stays on your device
- **Cross-device sync** for chats, settings, and encrypted API keys
- **Bring your own key** — use your own API keys for direct provider access
