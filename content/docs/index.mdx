AgentOne is an AI agent that lives on your computer. Tell it what you need in plain language, and it can answer questions, research topics, work with your files, run commands, use your other apps, and keep tasks running on a schedule.

![The AgentOne desktop app with a chat open. AgentOne searched the web, saved a packing list to the desktop, and answered with an itinerary table and a tip.](/images/docs/overview/hero.png)

## What AgentOne Can Do

- **Get real work done.** AgentOne can search the web, read pages, create and edit files, run terminal commands, and change its own settings, asking for your approval first when it matters. See [Tools & Approvals](/docs/agent/tools-and-approvals).
- **Use the apps on your computer.** With [Computer Use](/docs/agent/computer-use), AgentOne can see and control other apps on macOS and Windows, like a person at the keyboard.
- **Work on a schedule.** [Scheduled Agents](/docs/agent/scheduled-agents) run a prompt for you automatically, like a weekday morning briefing.
- **Split up big tasks.** AgentOne can hand focused pieces of work to [subagents](/docs/agent/subagents) that run in parallel.
- **Remember what matters.** It can save [memories](/docs/chats/personalization) about you and [read your past chats](/docs/agent/chat-history) to pick up where you left off.
- **Keep long tasks going.** When a chat gets long, AgentOne [compacts](/docs/chats/long-chats) it so it never runs out of room.
- **Connect to more apps.** Install [extensions](/docs/extensions) from more than 50,000 entries in the official MCP Registry, or add your own MCP servers.
- **Use any model.** Sign in to use AgentOne's own model with monthly credits, or [bring your own keys](/docs/models) for more than 125 built-in providers, local models with Ollama and LM Studio, and any OpenAI-compatible API.

## Private by Default

AgentOne is a desktop app, so your chats, files, and API keys stay on your device. An AgentOne account is optional. If you sign in, AgentOne syncs your settings across your devices. Learn exactly what syncs and what stays local in [Sync & Privacy](/docs/account/sync-and-privacy).

AgentOne is open source under the AGPL-3.0 license. You can [browse the code on GitHub](https://github.com/The-Best-Codes/agent-one).

## Get Help from the Community

If you find a bug, want a feature, or just want to chat with the AgentOne community and team:

- [AgentOne Discord](https://www.agent-one.dev/discord): the fastest way to get help and hear about new releases.
- [AgentOne Forum](https://forum.agent-one.dev): a public forum for questions and feature requests.
- [Report a bug on GitHub](https://github.com/AgentOne-Dev/agent-one-public/issues/new): the public issue tracker for the desktop app.
