AgentOne is a desktop AI app for macOS, Windows, and Linux. You can chat, research a topic, work with files, connect extensions, and schedule an agent to run later. Use AgentOne's built-in model, bring your own provider, or run a model on your computer.

These guides cover the current desktop app, including the changes in **1.1.1**. Screenshots show the macOS app; most controls work the same way on Windows and Linux.

## A few things to know

**The model and the app do different jobs.** AgentOne manages your chats and tools. The selected provider runs the model and determines its capabilities, availability, and usage limits. Adding a model to a list doesn't give your account access to it.

**Tools do real work.** A model can request a tool call, and AgentOne can run it after any required approval. You can choose the approval behavior for a chat and configure individual tools. Start with [the approval guide](/docs/tools/approvals) before giving an agent access to files or services.

**Scheduled agents run on your device.** Each run creates a new chat. Your computer, provider, and extensions need to be available for the work to finish. See [how scheduling works](/docs/scheduled-agents).

**Settings sync isn't a backup of everything.** Extensions and provider setup are configured separately on each device. Read [what sync includes](/docs/account/data-and-sync) before moving to another computer.
