AgentOne is built with [Tauri](https://tauri.app/) and [React](https://react.dev/). Follow the steps below to get it running locally.

## Prerequisites

Before you begin, make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- [Bun](https://bun.com/)
- [Rust & Tauri prerequisites](https://tauri.app/start/prerequisites/)

<Callout type="warn" title="Windows">
  On Windows, you also need: - [CMake](https://cmake.org/download/) - LLVM —
  install with `winget install LLVM.LLVM` - NASM — install with `winget install
  NASM.NASM`
</Callout>

## Setup

<Steps>
<Step>
### Clone the repository

```bash
git clone https://github.com/The-Best-Codes/agent-one.git
```

</Step>

<Step>
### Install dependencies

```bash
cd agent-one && bun install
```

</Step>

<Step>
### Run in development mode

```bash
bun run tauri dev
```

</Step>
</Steps>

## Building for Production

To create a production build:

```bash
bun run tauri build
```

This will generate platform-specific binaries in the `src-tauri/target/release` directory.
