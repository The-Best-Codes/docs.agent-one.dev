AgentOne supports [MCP (Model Context Protocol)](https://modelcontextprotocol.io/) servers, allowing you to extend the agent with custom tools and integrations.

## Transport Modes

MCP servers can connect using two transport modes:

### stdio

Runs a local command on your machine. The agent communicates with the server through standard input/output.

| Setting               | Description                                    |
| --------------------- | ---------------------------------------------- |
| Command               | The command to execute (e.g., `npx`, `python`) |
| Arguments             | Command-line arguments                         |
| Environment variables | Key-value pairs passed to the process          |

### HTTP

Connects to a remote MCP server over HTTP.

| Setting        | Description                           |
| -------------- | ------------------------------------- |
| URL            | The server endpoint URL               |
| Custom headers | HTTP headers to include with requests |

## Server Settings

All MCP servers share these common settings:

| Setting           | Description                                                        |
| ----------------- | ------------------------------------------------------------------ |
| Name              | Display name for the server                                        |
| Enabled           | Toggle the server on or off                                        |
| Timeout (ms)      | Maximum time to wait for a response                                |
| Requires approval | Prompt for user approval before the agent uses this server's tools |

## Global Settings

| Setting             | Default | Description                                          |
| ------------------- | ------- | ---------------------------------------------------- |
| Parallel load limit | 8       | Maximum number of MCP servers to load simultaneously |

You can configure MCP servers in **Settings → Extensions**.
