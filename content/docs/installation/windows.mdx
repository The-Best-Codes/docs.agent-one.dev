title: Windows Setup Guide

AgentOne runs on 64-bit Windows 10 (version 1809) or later, and Windows 11. There are two ways to install it:

- **Microsoft Store** (recommended). The Store installs and updates AgentOne for you, and you won't see any security warnings.
- **Installer (`.exe`)**. Download and run the installer yourself. AgentOne then updates itself.

## Download AgentOne

Head to:
https://www.agent-one.dev/download

Make sure the **Windows** tab is selected.

![The download page with the Windows tab selected, a Get it from Microsoft Store button, and a More download options section.](/images/docs/installation/download-windows.png)

1. The **Windows** tab.
2. **Get it from Microsoft Store** opens AgentOne in the Microsoft Store.
3. **More download options** reveals **Download Installer (.exe)**.

<Tab value="Installer (.exe)">

{/* prettier-ignore */}
<Steps>
<Step>

    ### Download the installer

    On the download page, click **More download options**, then **Download Installer (.exe)**.

</Step>
<Step>

    ### Keep the download if your browser warns you

    Because the installer isn't downloaded very often yet, Microsoft Edge and other browsers may say the file "isn't commonly downloaded." Open the browser's downloads list, click the **...** menu next to the file, choose **Keep**, then **Show more** and **Keep anyway**.

</Step>
<Step>

    ### Run the installer

    Open the downloaded file. If Windows shows **Windows protected your PC**, click **More info**, then **Run anyway**.

    In the **AgentOne Setup** window, click **Next** and follow the prompts. The defaults work for most people.

</Step>
<Step>

    ### Open AgentOne

    When setup finishes, launch **AgentOne** from the Start menu. Then follow the [Quickstart](/docs/quickstart).

</Step>
</Steps>

## Troubleshooting

### Microsoft Defender SmartScreen blocks the installer

SmartScreen warns about apps that haven't been downloaded many times yet. If you downloaded the installer from `agent-one.dev` or the official GitHub releases page, it's safe to continue with **More info** -> **Run anyway**. To avoid the warning entirely, install from the [Microsoft Store](https://apps.microsoft.com/detail/9NR1TW9NZZBW) instead.

### Links that start with `agent-one://` don't open AgentOne

AgentOne registers the `agent-one://` link type when it starts. Open AgentOne once after installing, then try the link again. See [Deep Links](/docs/reference/deep-links).

### The app shows "Automatic updates disabled"

That's expected for Microsoft Store installs. The Store keeps AgentOne up to date. See [Updating AgentOne](/docs/installation/updating).
