## Microsoft Store

The Microsoft Store is the recommended installation method on Windows. Open [AgentOne in the Microsoft Store](https://apps.microsoft.com/detail/9NR1TW9NZZBW?hl=en-us&gl=US&ocid=pdpshare), or search for **AgentOne** in the Store app. Choose the installation option shown there and follow the prompts.

When installation finishes, open AgentOne from the Start menu. The Store manages updates for that installation.

## Standalone installer

Use this if you need the direct installer instead of the Store package.

1. Open the [download page](https://www.agent-one.dev/download) and select **Windows**.
2. Expand **More download options** if the standalone installer isn't shown immediately. Download the `.exe` that matches your system. You can also find installers in the [official release assets](https://github.com/AgentOne-Dev/agent-one-public/releases/latest).
3. Find the downloaded file in your browser's Downloads list or File Explorer's Downloads folder, and open it.
4. In the setup wizard, choose **Next**, review the installation folder, and continue with installation.
5. Choose **Finish**, then open AgentOne from the shortcut or Start menu.

## A download or launch is blocked

First check that the file came from the official download page or linked release assets. If you downloaded it elsewhere, get a fresh official copy. The Microsoft Store route usually avoids the warnings associated with a standalone installer.

A SmartScreen reputation warning means Windows doesn't have enough reputation information for the file; it doesn't establish that a file is safe. Review the source and the exact warning before deciding to proceed. On a managed computer, ask your administrator if policy blocks installation.

## The app won't start

Confirm that you downloaded the correct architecture and completed setup. Note the exact error message and whether you used the Store or standalone installer, then [contact support](https://www.agent-one.dev/discord). Avoid repeatedly switching between install methods while diagnosing the issue; duplicate installations can make it unclear which copy you're opening.
