There are two primary ways to install AgentOne on Windows. We recommend installing from agent-one.dev.

## Install from agent-one.dev (recommended)

{/* prettier-ignore */}
<Steps>
<Step>
      
      ### Sign in to your AgentOne account
      
      Navigate to https://www.agent-one.dev/sign-in in your browser to sign in. If you don't have an account, [sign up instead](https://www.agent-one.dev/sign-up).
      
</Step>
<Step>
  
    ### Navigate to [your dashboard](https://www.agent-one.dev/dashboard)
  
</Step>
<Step>
  
    ### Download the desktop app installer
    
    Click the `Download app` button in the bottom left of the sidebar.
    
    {/* TOFILL: Image here */}
    
    You'll be redirected to a download page, which will attempt to automatically detect your operating system. Make sure the `Windows` tab at the top of the page is selected:
    
    {/* TOFILL: Image here */}
    
    Now click `Download AgentOne for Windows`.
    
    <Callout>If you see a warning from Windows or your browser, or you are unable to download the file, reference the [Download Blocked by Windows](#download-blocked-by-windows) troubleshooting section.</Callout>
  
</Step>
<Step>
  
    ### Run the installer
    
    You're almost done! After downloading the installer, open it (click or double-click the `.exe` file) and follow the prompts to install AgentOne on your system. If you get stuck, refer to the [Windows Installer](#windows-installer) troubleshooting section below.
  
</Step>
</Steps>

## Install from GitHub

<Callout>
  If you followed the steps in the [Install from
  agent-one.dev](#install-from-agent-onedev-recommended) section, you can skip
  this section.
</Callout>

{/* prettier-ignore */}
<Steps>
<Step>
      
      ### Find AgentOne on GitHub Releases
      
      Open https://github.com/AgentOne-Dev/agent-one-public/releases.
      
</Step>
<Step>
  
    ### Select the latest release
    
    Usually, the latest release is the first release on the list. You'll see a green `Latest` badge next to the latest stable release. If the release has a `Pre-release` badge or title, don't use it unless you're a developer.
    
    ![GitHub Releases page showing the latest release with a green "Latest" badge](/images/docs/installation/gh-releases/github-releases-latest.png)
    
    Once you've found the latest release, click on its title (for example, `AgentOne 1.0.0`) to navigate to that release.
  
</Step>
<Step>
  
    ### Download the desktop app installer
    
    Scroll to the bottom of the release page and expand the `Assets` accordion.
    Look for a file named `AgentOne_x.x.x_x64-setup.exe` and click on it to download it.
    
    <Callout>Make sure you download the `.exe` file, not the `.exe.sig` file.</Callout>
    
    ![GitHub release assets showing the AgentOne installer file](/images/docs/installation/gh-releases/assets-exe-selected.png)
  
</Step>
<Step>
  
    ### Run the installer
    
    You're almost done! After downloading the installer, open it (click or double-click the `.exe` file) and follow the prompts to install AgentOne on your system. If you get stuck, refer to the [Windows Installer](#windows-installer) troubleshooting section below.
  
</Step>
</Steps>

## Troubleshooting

### Download Blocked by Windows

If your system is equipped with Windows Defender SmartScreen or similar security features, you may encounter warnings when attempting to download or run the installer. This is not a problem with AgentOne or Windows, it's a feature built-in to your computer.

![Windows Defender SmartScreen warning](/images/docs/installation/windows/smartscreen-blocked-download.png)

If you see a SmartScreen warning, look for an option like `Advanced`, `Proceed anyway`, or similar. In Microsoft Edge, click the three dots next to the download and select `Keep`. You may see an additional screen warning you that AgentOne isn't commonly downloaded. Next to the `Delete` button, click the dropdown arrow and select `Keep anyway`.

![Keep anyway option](/images/docs/installation/windows/smartscreen-keep-anyway.png)

The file should then begin downloading. Once it finishes, you can click "Open file" to run the installer and follow the prompts to complete the AgentOne installation. If you encounter any issues while running the installer, see the [Windows Installer](#windows-installer) troubleshooting section.

![File downloaded successfully in Microsoft Edge](/images/docs/installation/windows/file-downloaded.png)

### Windows Installer

If you get stuck or are unsure what option to select while running the AgentOne installer, reference this section. It will walk you through running the Windows installer `exe` that you downloaded in either of the previous sections.
