AgentOne runs on macOS 14.0 (Sonoma) or later, on both Apple Silicon and Intel Macs.

## Install AgentOne on macOS

{/* prettier-ignore */}
<Steps>
<Step>

    ### Download the desktop app

    Head to:
    https://www.agent-one.dev/download

    Make sure the **macOS** tab is selected.

    ![The download page with the macOS tab selected and numbered download buttons.](/images/docs/installation/download-macos.png)

    1. The **macOS** tab.
    2. **Download Apple Silicon (.dmg)** for Macs with an Apple chip (M1 or newer).
    3. **Download Intel (.dmg)** for older Macs with an Intel processor.

    Click the button that matches your Mac.

    <Callout title="Not sure which one to pick?">
      Click the Apple menu in the top-left corner of your screen and choose `About This Mac`. If the `Chip` field says something like `Apple M1`, `Apple M3`, or `Apple M4`, choose **Apple Silicon**. If it shows a `Processor` field with something like `Intel Core i5`, choose **Intel**.

      If you pick the wrong one, AgentOne may not open or may run slowly. To learn more, read [Apple's support article](https://support.apple.com/en-us/116943).
    </Callout>

</Step>
<Step>

    ### Open the `.dmg` file

    When the download finishes, open the `.dmg` file from your browser or from the `Downloads` folder in Finder.

</Step>
<Step>

    ### Move AgentOne to Applications

    An installer window opens.

    ![The AgentOne installer window showing the AgentOne icon on the left and the Applications folder on the right.](/images/docs/installation/macos-dmg.png)

    Drag **AgentOne** (1) onto the **Applications** folder (2).

</Step>
<Step>

    ### Open AgentOne

    Open the `Applications` folder and double-click **AgentOne**, or find it in Launchpad or Spotlight.

    The first time you launch the app, macOS may ask you to confirm that you want to open an app downloaded from the internet. Click **Open** to continue.

</Step>
<Step>

    ### Finish setup

    Follow the [Quickstart](/docs/quickstart) to sign in or connect your own AI provider.

</Step>
</Steps>

AgentOne updates itself on macOS. See [Updating AgentOne](/docs/installation/updating).

## Troubleshooting

### "AgentOne.app" was downloaded from the internet

This is a normal macOS message the first time you open many apps downloaded outside the App Store. If you downloaded AgentOne from `agent-one.dev` or the official GitHub releases page, click **Open**.

### "AgentOne.app" can't be opened because Apple cannot check it for malicious software

macOS Gatekeeper may block an app until you allow it. AgentOne releases are signed and notarized, but you might still see this on some setups. To allow it:

1. Try to open AgentOne once so macOS shows the warning.
2. Open **System Settings**.
3. Go to **Privacy & Security**.
4. Scroll down to the **Security** section.
5. Click **Open Anyway** next to the message about AgentOne.
6. Confirm by clicking **Open**.

Apple notes that the **Open Anyway** button only appears for about an hour after you try to open the app.

### "AgentOne.app" is damaged and can't be opened

This usually means the download was interrupted or modified. Try these steps:

1. Delete `AgentOne.app` from your `Applications` folder and delete the old `.dmg` file.
2. Download a fresh copy for the correct chip (Apple Silicon or Intel).
3. Open the new `.dmg` and drag AgentOne into `Applications` again.

If you still see the message, you can clear the quarantine flag macOS added to the download. Open the **Terminal** app (press `Command + Space`, type `Terminal`, and press `Return`), then run:

```bash
xattr -cr /Applications/AgentOne.app
```

This removes the "downloaded from the internet" flag so macOS checks the app normally again.

<Callout type="warn">
  Only run this command if you downloaded AgentOne from `agent-one.dev` or the
  official GitHub releases page.
</Callout>

### AgentOne asks for permissions

AgentOne only asks for macOS permissions when a feature needs them:

- **Notifications** when AgentOne wants to tell you a response is ready. See [Agent Notifications](/docs/settings/chats#agent-notifications).
- **Accessibility** and **Screen Recording** if you use [Computer Use](/docs/agent/computer-use).
