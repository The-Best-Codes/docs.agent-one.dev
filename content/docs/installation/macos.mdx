## Download and install

1. Open the [download page](https://www.agent-one.dev/download) and select **macOS**.
2. Choose **Apple Silicon** for a Mac with an Apple chip, or **Intel** for a Mac with an Intel processor. Check **Apple menu → About This Mac** if you're unsure.
3. Open the downloaded `.dmg` file in Finder.
4. Drag **AgentOne.app** into **Applications**.
5. Open AgentOne from Applications. If macOS shows the usual downloaded-from-the-internet confirmation, confirm that this is the app you downloaded and choose **Open**.

Launch the copy in Applications rather than the copy inside the disk image. You can eject the disk image after copying the app.

## The app won't open

### The developer can't be verified

If you downloaded the app from the official website or release page and want to allow it, try opening it once, then go to **System Settings → Privacy & Security**. Look for AgentOne's **Open Anyway** option and follow the confirmation. A managed Mac may need your administrator's help. [Apple explains these alerts and exceptions](https://support.apple.com/en-us/102445).

### The app is damaged

Download a fresh copy for the correct architecture, replace the app in Applications, and try again. A damaged-app alert can mean a corrupted or altered download; it isn't the same as an unidentified-developer alert. If it persists, send the exact message, app version, and macOS version to [support](https://www.agent-one.dev/discord). See [Apple's explanation of damaged-app alerts](https://support.apple.com/en-us/102445).

### AgentOne opens, but a local extension can't start

A desktop app may have a different executable search path from your terminal. Check that the extension's runtime is installed, and use its absolute executable path when needed. For example, the command might need a full path to `node`, `npx`, or `uvx`. See [extension troubleshooting](/docs/troubleshooting/extensions).

## Update

Check **Configure AgentOne → Help & Updates**. If you install a newer version manually, quit AgentOne, copy the new app into Applications, and reopen that copy. Export important chats before making changes to application data.
