---
title: "Debian and Ubuntu"
description: "Install the downloaded .deb with dependency resolution."
---

Download the `.deb` for your architecture from the [download page](https://www.agent-one.dev/download) or [release assets](https://github.com/AgentOne-Dev/agent-one-public/releases/latest).

In a terminal, go to the download folder and install the exact file:

```bash
sudo apt install ./AgentOne_VERSION_amd64.deb
```

Replace `AgentOne_VERSION_amd64.deb` with the downloaded filename. Including `./` tells apt to install a local file; apt can resolve dependencies from your configured repositories.

Open AgentOne from the application menu. If you can't find it, check that apt finished successfully and read any dependency error before retrying.

For later manual updates, install the newer `.deb` through the same method. Check [Help & Updates](/docs/settings/updates) for application and catalog versions.

If a dependency isn't available for your distribution release, send the package filename, distribution version, and full error to [support](https://www.agent-one.dev/discord). You can also review the [AppImage option](/docs/installation/linux/appimage).
