---
title: "Fedora and RHEL"
description: "Install an RPM using your distribution package manager."
---

Download an `.rpm` for your architecture from the [download page](https://www.agent-one.dev/download) or [release assets](https://github.com/AgentOne-Dev/agent-one-public/releases/latest).

Open a terminal in the download folder and install the exact file:

```bash
sudo dnf install ./AgentOne-VERSION-1.x86_64.rpm
```

Replace the example filename with the one you downloaded. DNF resolves dependencies using your configured repositories.

Launch AgentOne from the application menu when installation finishes. Install newer RPMs using the same package manager so it can track the application and its dependencies.

Package compatibility depends on your distribution release and available dependencies. If installation fails, record the full error and your distribution version, then [ask for help](https://www.agent-one.dev/discord). Don't force an RPM past unresolved dependencies. Review the [other Linux formats](/docs/installation/linux) if needed.
