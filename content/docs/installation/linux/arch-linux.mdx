---
title: "Arch Linux"
description: "Use the AUR package or a direct Linux download."
---

The AUR package is [`agent-one-bin`](https://aur.archlinux.org/packages/agent-one-bin). Review the package details and build instructions before installing it. AUR packaging and update availability may differ from the direct release.

If you already use an AUR helper, install with that helper:

```bash
yay -S agent-one-bin
```

Or:

```bash
paru -S agent-one-bin
```

These commands assume the chosen helper is installed. After installation, open AgentOne from your application menu.

Update through the same package manager. Check [Help & Updates](/docs/settings/updates) for the application version and downloaded catalogs.

If the AUR package is unavailable or outdated, check the [official release assets](https://github.com/AgentOne-Dev/agent-one-public/releases/latest) and [AppImage guide](/docs/installation/linux/appimage). For a packaging issue, include the package version, build output, and distribution details when asking for help.
