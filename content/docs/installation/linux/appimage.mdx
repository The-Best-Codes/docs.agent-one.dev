---
title: "Run the AppImage"
description: "Download, make executable, and launch the standalone Linux build."
---

## Download

Select **Linux** on the [download page](https://www.agent-one.dev/download), then download an AppImage for your architecture. If it isn't shown, check the [release assets](https://github.com/AgentOne-Dev/agent-one-public/releases/latest).

## Launch

Open a terminal in the download folder. Replace the example filename below with the exact filename you downloaded:

```bash
chmod +x ./AgentOne_VERSION_amd64.AppImage
./AgentOne_VERSION_amd64.AppImage
```

You can also use your file manager's permissions dialog to allow execution, then double-click the file. Keep it in a stable location if you make a launcher pointing to it.

## If it fails

Run the AppImage from a terminal and read the error. An architecture mismatch needs a different download. A missing FUSE library needs the appropriate package for your distribution; use your distribution's instructions rather than installing a package for a different release.

If signing in or extension authorization doesn't return to AgentOne, check desktop URL registration. Consider a [native package](/docs/installation/linux) when you need reliable desktop integration or scheduled launches.

## Update

Use [Help & Updates](/docs/settings/updates) to check for an app update. If replacing the file manually, close the old process and reopen the new file. Update any launcher pointing to the previous filename. Don't remove application data as part of an ordinary update.
