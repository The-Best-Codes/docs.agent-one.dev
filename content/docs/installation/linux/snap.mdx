AgentOne is available on the [Snap Store](https://snapcraft.io/agent-one) and works on any Linux distribution with snap support. If you have an app center that supports Snapcraft installed, open it and search `AgentOne`, then install AgentOne by following the steps in your app-store.

## Install from the Snap Store

<Steps>
<Step>

    ### Install AgentOne

    Open a terminal and run:

    ```bash
    sudo snap install agent-one
    ```

</Step>
<Step>

    ### Launch AgentOne

    Once the installation is complete, you can launch AgentOne from your application menu or by running `agent-one` in your terminal.

</Step>
</Steps>
