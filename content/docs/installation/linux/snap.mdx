---
title: "Snap Store"
description: "Install and update AgentOne through Snap."
---

Open [AgentOne in the Snap Store](https://snapcraft.io/agent-one), or search for **AgentOne** in a software center that supports Snap.

With snapd installed, you can use:

```bash
sudo snap install agent-one
```

Launch AgentOne from the application menu. If you need to request a package refresh:

```bash
sudo snap refresh agent-one
```

The Store page shows the version available in each channel. Store publishing can lag the direct release, so check that page before assuming an in-app feature is present.

Snap confinement can affect file access, commands, and desktop integration. If a tool can see a path in your terminal but not in AgentOne, check the package's permissions and interfaces. Include the Snap installation method when [reporting an issue](/docs/troubleshooting).

Need a different format? See [Linux installation](/docs/installation/linux).
