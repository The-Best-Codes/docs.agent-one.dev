AgentOne is free to download and runs on macOS, Windows, and Linux. You don't need an account or a credit card to install it.

## System Requirements

| Platform | Requirement                                                                                                                           | Download options                          |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| macOS    | macOS 14.0 or later, Apple Silicon or Intel                                                                                           | `.dmg`                                    |
| Windows  | Windows 10 (version 1809) or later, 64-bit                                                                                            | Microsoft Store, `.exe` installer         |
| Linux    | 64-bit (x86_64), glibc 2.38 or newer (like Ubuntu 24.04+, Debian 13+, Fedora 40+, or Linux Mint 22+), with `webkit2gtk-4.1` available | AppImage, `.deb`, `.rpm`, Snap Store, AUR |

## Download AgentOne

Go to the download page:

https://www.agent-one.dev/download

The page detects your operating system and selects the right tab. If it picked the wrong one, click **macOS**, **Windows**, or **Linux** at the top.

![The AgentOne download page with the macOS tab selected and download buttons for Apple Silicon and Intel.](/images/docs/installation/download-macos-plain.png)

Every release is also available on the [GitHub releases page](https://github.com/The-Best-Codes/agent-one/releases/latest).
