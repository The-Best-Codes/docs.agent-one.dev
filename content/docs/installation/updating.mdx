title: Updating AgentOne

---

AgentOne checks for updates each time it starts. When a new version is available, you'll see an **Update Available** window.

![The Update Available dialog with a Remind me in 1 day button, a menu for other reminder times, and an Update button.](/images/docs/installation/update-available.png)

- Click **Update** to go to the update controls in `Settings` -> `Help & Updates`, then click **Download & Install**. AgentOne shows the download progress, installs the update, and restarts.
- Click **Remind me in 1 day** to be reminded tomorrow, or use the arrow next to it to choose **3 days**, **1 week**, or **2 weeks**.

## Check for Updates Manually

1. Open `Settings` -> `Help & Updates`.
2. Under **App**, click **Check Now**.
3. If an update is available, click **Download & Install**.

![The Help & Updates section showing the current version, update status, Model List, Extension List, and Help links.](/images/docs/settings/help-and-updates.png)

## Installs That Update Themselves Elsewhere

Some installs are kept up to date by your system instead of by AgentOne. In that case, `Help & Updates` says **Automatic updates disabled** and **Update AgentOne through your software manager instead**.

| Installed from  | How to update                                 |
| --------------- | --------------------------------------------- |
| Microsoft Store | The Store updates AgentOne automatically.     |
| Snap Store      | Snap updates AgentOne automatically.          |
| AUR             | Update with your AUR helper, like `yay -Syu`. |

## What's New

After an update, AgentOne shows **What's New** with the release notes for the new version.

![The What's New in v1.2.2 dialog describing mentions for files and skills in the message box.](/images/docs/installation/release-notes.png)

You can read the notes for any past version in `Settings` -> `Help & Updates` -> **Release notes**. Every release is also listed on [GitHub](https://github.com/The-Best-Codes/agent-one/releases), and big releases get a post on the [AgentOne blog](https://www.agent-one.dev/blog).

## Uninstalling AgentOne

<Tabs items={["macOS", "Windows", "Linux"]}>
<Tab value="macOS">
Quit AgentOne, then drag **AgentOne** from your `Applications` folder to the Trash.
</Tab>
<Tab value="Windows">
Open **Settings** -> **Apps** -> **Installed apps**, find **AgentOne**, and choose **Uninstall**.
</Tab>
<Tab value="Linux">
Remove it with the same tool you installed it with, for example `sudo apt remove agent-one`, `sudo dnf remove agent-one`, `sudo snap remove agent-one`, or `yay -R agent-one-bin`. For the AppImage, delete the file.
</Tab>
</Tabs>

Uninstalling the app doesn't delete your chats and settings. To remove them too, delete AgentOne's data folders listed in [Data Locations](/docs/reference/data-locations).
