AgentOne runs on 64-bit (x86_64) Linux. Pick the option that fits your distribution:

| Option                               | Best for                                 | Updates                       |
| ------------------------------------ | ---------------------------------------- | ----------------------------- |
| [AppImage](#appimage)                | Any distribution, no installation needed | Built-in updater              |
| [`.deb` package](#debian-and-ubuntu) | Debian, Ubuntu, Linux Mint, Pop!\_OS     | Built-in updater              |
| [`.rpm` package](#fedora-and-rhel)   | Fedora, RHEL, openSUSE                   | Built-in updater              |
| [Snap Store](#snap-store)            | Any distribution with snap support       | Snap updates it automatically |
| [AUR](#arch-linux-aur)               | Arch Linux, Manjaro, EndeavourOS         | Your AUR helper               |

## Download from agent-one.dev

The AppImage, `.deb`, and `.rpm` downloads are on the download page:

https://www.agent-one.dev/download

![The download page with the Linux tab selected and buttons for the AppImage, .deb, and .rpm packages.](/images/docs/installation/download-linux.png)

1. The **Linux** tab.
2. **Download AppImage**, which works on almost any distribution.
3. **Download .deb (Debian/Ubuntu)** for Debian-based distributions.

## AppImage

The AppImage runs without installing anything.

{/* prettier-ignore */}
<Steps>
<Step>

    ### Download the AppImage

    Click **Download AppImage** on the download page.

</Step>
<Step>

    ### Make it executable

    Open a terminal in the folder you downloaded it to (usually `~/Downloads`) and run:

    ```bash
    chmod +x AgentOne_*.AppImage
    ```

    You can also right-click the file in your file manager, open **Properties**, and turn on **Allow executing file as program**.

</Step>
<Step>

    ### Run AgentOne

    Double-click the file, or run it from the terminal:

    ```bash
    ./AgentOne_*.AppImage
    ```

</Step>
</Steps>

<Callout title="AppImage won't start?">
  Some distributions need FUSE to run AppImages. On Ubuntu 22.04 and newer,
  install it with `sudo apt install libfuse2t64` (or `libfuse2` on older
  releases).
</Callout>

## Debian and Ubuntu

{/* prettier-ignore */}
<Steps>
<Step>

    ### Download the package

    Click **Download .deb (Debian/Ubuntu)** on the download page.

</Step>
<Step>

    ### Install it

    Double-click the file to open it in your software center, or install it from a terminal:

    ```bash
    sudo apt install ./AgentOne_*.deb
    ```

</Step>
<Step>

    ### Launch AgentOne

    Open AgentOne from your application menu, or run `agent-one` in a terminal.

</Step>
</Steps>

## Fedora and RHEL

## Snap Store

AgentOne is on the [Snap Store](https://snapcraft.io/agent-one). Search for `AgentOne` in your app store, or install it from a terminal:

```bash
sudo snap install agent-one
```

Then launch AgentOne from your application menu or run `agent-one`. Snap keeps AgentOne up to date automatically.

## Arch Linux (AUR)

Install the [`agent-one-bin`](https://aur.archlinux.org/packages/agent-one-bin) package with your favorite AUR helper:

```bash
yay -S agent-one-bin
```

or:

```bash
paru -S agent-one-bin
```

Update AgentOne the same way you update other AUR packages.

## Troubleshooting

### AgentOne doesn't show up in my application menu after installing the AppImage

AppImages aren't installed, so they don't add a menu entry by themselves. Use a tool like [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) or AppImageLauncher to integrate it, or switch to the `.deb`, `.rpm`, Snap, or AUR package.

### AgentOne can't save my API keys

AgentOne stores API keys in your system keyring through the Secret Service (provided by GNOME Keyring or KWallet). If no keyring is available, AgentOne saves keys to a local file instead and moves them into the keyring once one is available. If keys don't persist, install `gnome-keyring` (or enable KWallet) and restart AgentOne.

### Computer Use can't see or control an app

[Computer Use](/docs/agent/computer-use) on Linux needs your desktop's accessibility service (AT-SPI), which GNOME and KDE run by default. If AgentOne can't see inside an app, quit and reopen that app. On Wayland, screenshots and input only work with apps running under X11 or XWayland. See [Set Up on Linux](/docs/agent/computer-use#set-up-on-linux).

### Notifications don't appear

Make sure notifications are enabled for AgentOne in your desktop environment's settings, and check [Agent Notifications](/docs/settings/chats#agent-notifications) in AgentOne.
