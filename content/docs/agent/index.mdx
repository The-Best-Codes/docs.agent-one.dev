A chatbot answers questions. An agent can also **take actions**: search the web, work with your files, run commands, use other apps, and keep working on a schedule. AgentOne decides which actions to take based on what you ask, and checks with you, or with [Auto mode](/docs/agent/auto-mode), before anything sensitive.

## Tips for Getting Great Results

- **Say what "done" looks like.** "Summarize this PDF in five bullet points and save them to `~/Desktop/summary.md`" works better than "look at this PDF."
- **Let it ask.** For bigger jobs, try "Ask me any questions you need before you start."
- **Check the steps.** Each tool AgentOne uses shows up in the chat. Click a step to see exactly what it did.
- **Use the right model.** Agent tasks work best with models that support tools. Use the **Tools** filter in the [model selector](/docs/models/choosing-a-model) to find them.
