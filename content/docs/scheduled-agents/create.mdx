## Ask AgentOne to create it

Open **Scheduled Agents → New → Ask AgentOne to create it**. This opens a chat with a setup request. Tell the agent what should happen, when it should run, and what the finished result should contain.

For example:

> Create a weekday 8 AM research summary. Check these official release pages, include links, and return the summary in the chat. Ask me for any missing details before creating it.

The model needs tool support and the scheduled-agent tools must be enabled. Creation requires approval by default. Review the proposed title, schedule, and complete prompt, then check that the new entry appears in Scheduled Agents. A conversational promise isn't the same as a saved schedule.

## Enter it manually

1. Open **Scheduled Agents → New**.
2. Choose **or enter manually**.
3. Enter a descriptive **Title**.
4. Enter the **Cron schedule**.
5. Write the complete recurring **Prompt**.
6. Choose **Create** and check the saved entry.

## Cron examples

Use five fields in this order: **minute, hour, day of month, month, day of week**. The schedule uses the computer's local time. Review it again if you change the device's timezone.

| Expression    | Schedule                        |
| ------------- | ------------------------------- |
| `0 7 * * *`   | Every day at 7 AM               |
| `0 8 * * 1-5` | Monday through Friday at 8 AM   |
| `30 17 * * 5` | Fridays at 5:30 PM              |
| `0 */2 * * *` | Every two hours, on the hour    |
| `0 9 1 * *`   | First day of each month at 9 AM |

The saved entry shows a readable schedule. Hover or focus its schedule text to see the cron expression and calculated run times. A calculated “Last run” time describes the schedule's previous occurrence; it isn't proof that a task completed successfully.

## Test before relying on it

Try the prompt in an ordinary chat with the same model and tools. Then check the first scheduled run's chat for a successful answer and any pending approvals or errors. See [schedule troubleshooting](/docs/troubleshooting/schedules) if it doesn't run.
