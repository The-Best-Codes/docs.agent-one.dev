Use Cmd on macOS and Ctrl on Windows/Linux for the app's platform modifier.

## Shipped defaults

| Action                    | macOS        | Windows / Linux |
| ------------------------- | ------------ | --------------- |
| Focus the message input   | Cmd+L        | Ctrl+L          |
| Open settings             | Cmd+,        | Ctrl+,          |
| Start a new chat          | Cmd+N        | Ctrl+N          |
| Search chats              | Cmd+K        | Ctrl+K          |
| Toggle sidebar            | Cmd+B        | Ctrl+B          |
| Stop the current response | Shift+Escape | Shift+Escape    |

Search opens the sidebar search when expanded, or a search dialog when the sidebar is collapsed.

## Customize

Open **Configure AgentOne → Keyboard Shortcuts**. Use a shortcut's recording control, press the combination you want, and check the displayed result. Reset an individual shortcut if you need the default back.

Avoid assigning the same combination to several actions or choosing a combination your operating system already handles globally.

## Shortcuts inside text fields

The Keyboard Shortcuts tab includes a setting for running global shortcuts while typing in inputs. Enabling it can override familiar text-editing behavior. If a combination is swallowed while you're writing, check this option and the configured app action.

## Sending and interrupting

Submit and interrupt keys are configured under **Chats**, separately from the global shortcut list. The defaults are Enter to send and Cmd+Enter / Ctrl+Enter to interrupt a running response. With Enter submission, use Shift+Enter for a new line.

In the user-message editor, Escape cancels editing. Read the save button before submitting an edit because regeneration can restart the conversation from that point.
