`Settings` -> `Help & Updates` has four cards.

![The Help & Updates section with App, Model List, Extension List, and Help cards.](/images/docs/settings/help-and-updates.png)

## App

- **Current Version** shows which version of AgentOne you're running.
- **Check Now** checks for an update. If one is available, click **Download & Install**. See [Updating AgentOne](/docs/installation/updating).
- **Release notes** shows what changed in any version. Pick a version from the menu.

## Model List

The list of models and their details for built-in providers, from the [AI Model Directory](https://www.modeldirectory.dev). AgentOne updates it automatically every 24 hours. Click **Update now** to update it right away. See [Model Metadata](/docs/models/model-metadata).

## Extension List

The list of extensions from the MCP Registry. AgentOne updates it automatically every 24 hours, and shows progress while it downloads. Click **Update now** to update it right away. See [Extensions](/docs/extensions).

## Help

- **Take the tour** restarts the guided tour of the app.
- **Report a bug** opens a new issue on [GitHub](https://github.com/The-Best-Codes/agent-one/issues/new).
- **Get help on Discord** opens the [AgentOne Discord](https://www.agent-one.dev/discord).
- **Read the docs** opens this documentation.
