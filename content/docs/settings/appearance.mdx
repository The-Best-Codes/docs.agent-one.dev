## Theme and colors

Use **System** to follow the operating system's light/dark appearance, or select a fixed mode. Primary color changes the accents. Background tint and strength control the interface's background color treatment.

Check text and controls against the background after changing several color settings. A striking color combination is less useful if message text or approval controls become hard to read.

## Typography and shape

Choose the font and text scale, then adjust roundness if you want more square or rounded controls. Text scale changes the interface size; it doesn't change how many tokens a provider can process.

## Chat backgrounds

Choose a provided background or a custom image using the available controls. Position, zoom, blur, dimming, tint, and shading help make the image work behind a conversation.

After selecting an image, check a chat with real messages and tool cards. Adjust the background so those remain readable. A local image or file may need to be available separately on another device even when appearance preferences sync.

## Layout

The collapsed sidebar options control how navigation remains available when the main sidebar is closed. Other layout choices, such as the floating input, change where the composer sits.

Use [keyboard shortcuts](/docs/settings/keyboard-shortcuts) for quick sidebar toggling and input focus. Use the individual reset controls when you want to restore a setting's default.
