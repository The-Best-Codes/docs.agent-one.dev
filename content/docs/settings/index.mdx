---
title: "Configure AgentOne"
description: "Find the setting that changes the behavior you want."
---

Choose **Configure AgentOne** from the sidebar, or press **Cmd+,** on macOS / **Ctrl+,** on Windows/Linux. Settings normally opens on Account. Use the tabs to navigate, then **Back to Chat** to return.

| Tab                | What you'll find                                                                                |
| ------------------ | ----------------------------------------------------------------------------------------------- |
| Account            | Sign-in, usage, sync, your name, instructions, and memory                                       |
| Appearance         | Theme, colors, typography, backgrounds, and layout                                              |
| Chats              | Sorting, grouping, notifications, message actions, submit/interrupt keys, streaming, and titles |
| Keyboard Shortcuts | Global shortcut assignments and behavior inside text inputs                                     |
| Performance        | Rendering limits, long-chat virtualization, and extension loading concurrency                   |
| Providers          | Built-in/local/custom model connections and text-to-speech                                      |
| Tools              | Built-in tool availability, approval requirements, and tool limits                              |
| Help & Updates     | App version, release notes, app updates, and catalog downloads                                  |

Extensions and scheduled agents are separate sidebar pages. Provider dialogs and extension Advanced views use draft changes with save controls. Many ordinary settings apply when you change their control; don't wait for a universal Save button that isn't there.

Use the reset button beside a setting when you want its default back. Reset only the relevant setting when troubleshooting, so you can tell which change resolved the problem.

For settings sync across devices, see [data and sync](/docs/account/data-and-sync).
