---
title: "Search and organize chats"
description: "Find conversations, choose their order, and manage titles."
---

Use **Search chats…** in the sidebar. Press **Cmd+K** on macOS or **Ctrl+K** on Windows/Linux to focus search. When the sidebar is collapsed, the shortcut opens the search dialog.

## Search titles or content

Open **Search options** beside the search field. **Search content** controls whether message content is included. Turn it off for a narrower title search; leave it on when you remember a phrase from the conversation but not its title.

Content search can take longer in a large chat collection. Start with a distinctive word or phrase, then broaden the search if needed. If operators cause unexpected results, turn **Allow search operators** off and try ordinary text.

Search filters the visible list. Clear the query to return to all chats. Time groups aren't shown while searching.

## Choose the sidebar order

Open **Configure AgentOne → Chats** and choose a chat sort order:

| Option                      | What moves a chat                                               |
| --------------------------- | --------------------------------------------------------------- |
| **Recently messaged first** | A new message in the conversation; this is the default          |
| **Recently active first**   | Activity such as reopening a chat or changing its chat settings |
| **Newest chats first**      | The time the chat was created                                   |

Use Recently messaged first if reopening an old chat shouldn't move it above a conversation you're actively writing in.

## Group by time

Enable sidebar time grouping in Chat settings to divide the full list into date ranges such as today and earlier conversations. Grouping is off by default and doesn't apply to search results.

## Rename a chat

Open the menu beside a chat title and use the title-changing action. A specific title makes later searches easier: **Website launch checklist** is more useful than **New chat**.

Automatic titles can come from the model or from your first message, depending on [title-generation settings](/docs/settings/chat-behavior). A title-generation failure doesn't necessarily mean the conversation failed.

## Work with several chats

Use the sidebar's selection controls for bulk actions. Check the selected count before exporting or deleting. Exports and deletion are explained in [the next guide](/docs/chat/export-and-delete).
