---
title: Keyboard Shortcuts
description: Every default keyboard shortcut in AgentOne on macOS, Windows, and Linux.
---

You can change any of the shortcuts in the first table in [Keyboard Shortcut Settings](/docs/settings/keyboard-shortcuts).

## App Shortcuts

| Action                | macOS   | Windows and Linux | Notes                                               |
| --------------------- | ------- | ----------------- | --------------------------------------------------- |
| New chat              | `⌘ N`   | `Ctrl + N`        |                                                     |
| Focus the message box | `⌘ L`   | `Ctrl + L`        |                                                     |
| Search chats          | `⌘ K`   | `Ctrl + K`        | Opens a search window when the sidebar is collapsed |
| Toggle the sidebar    | `⌘ B`   | `Ctrl + B`        |                                                     |
| Open settings         | `⌘ ,`   | `Ctrl + ,`        |                                                     |
| Search settings       | `⌘ K`   | `Ctrl + K`        | On the settings page                                |
| Stop the response     | `⇧ Esc` | `Shift + Esc`     |                                                     |

## Message Box

These are set in [Chat Settings](/docs/settings/chats#behavior) instead of the shortcut editor.

| Action                                          | Default                                           |
| ----------------------------------------------- | ------------------------------------------------- |
| Send a message                                  | `Enter` (or `⌘/Ctrl + Enter` with **Submit Key**) |
| New line                                        | `Shift + Enter`                                   |
| Interrupt and send while AgentOne is responding | `⌘/Ctrl + Enter` (change with **Interrupt Key**)  |

## Editing a Message

| Action | Keys                                                              |
| ------ | ----------------------------------------------------------------- |
| Save   | `Enter` (or `⌘/Ctrl + Enter` if your **Submit Key** is set to it) |
| Cancel | `Esc`                                                             |

## Other

| Where                     | Keys    | Action             |
| ------------------------- | ------- | ------------------ |
| Rename chat window        | `Enter` | Save the new title |
| Guided tour               | `Esc`   | Close the tour     |
| Full-screen extension app | `Esc`   | Return to the chat |
