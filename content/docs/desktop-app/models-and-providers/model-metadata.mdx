---
title: Model Metadata
description: Understand the model metadata fields used by AgentOne.
---

When you add or edit a model in provider settings, AgentOne stores metadata that helps the UI behave correctly.

## Fields

### Model ID

The provider's raw model identifier.

### Display Name

The human-friendly label shown in the model picker.

### Context Window

Optional token limit metadata shown in the app UI.

### Max Output Tokens

Optional maximum output token metadata.

### Supports Text

Whether the model should be considered usable for normal text chat.

### Supports Tools

Whether the model should be treated as tool-capable.

### Supports Images

Whether the model should be treated as image-capable.

## Built-In Overrides

If you add a model with the same ID as a built-in model, AgentOne treats it as a metadata override.

This is useful when you want to correct or customize app-side capability metadata without changing the actual provider.
