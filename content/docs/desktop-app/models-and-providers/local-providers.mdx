title: Local Providers
description: Use built-in local providers such as Ollama and LM Studio in AgentOne.
---

AgentOne includes built-in support for these local providers:

- `Ollama`
- `LM Studio`

These appear in `Settings` -> `Providers` under `Local Providers`.

## Default Local Provider URLs

- Ollama: `http://127.0.0.1:11434/v1`
- LM Studio: `http://127.0.0.1:1234/v1`

## Automatic Model Discovery

AgentOne can automatically fetch local models when the provider is reachable.

For local providers, this can happen:

- when the app starts
- when you open the provider and use the `Auto` button in the Models section

## Ollama Notes

The built-in Ollama provider includes the `Origin: http://localhost` header by default.

If Ollama is installed and running, AgentOne should discover its available models automatically.

## Manual Model Entry

If automatic discovery does not work, you can still add a model manually with `Add Model`.

## When To Use Local Providers

Use them when you want:

- local-only inference
- offline or private workflows
- no cloud API billing for the model itself

For the dedicated Ollama walkthrough, see [Local LLMs with Ollama](/docs/guides/providers/ollama-local-llms).
