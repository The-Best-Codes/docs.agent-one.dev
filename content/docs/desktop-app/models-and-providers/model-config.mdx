---
title: Model Config
description: Adjust per-chat model behavior in AgentOne.
---

The button next to the model selector opens `Model Config`.

These values apply to the current chat.

## Available Settings

- `Temperature`
- `Top P`
- `Top K`
- `Frequency Penalty`
- `Presence Penalty`
- `Max Steps`
- `Max Tokens`
- `Seed`

## Resetting

If you change any values, the button shows a small indicator dot.

Use the reset button inside the panel to restore defaults.

## Notes

- leave fields empty to use model defaults where supported
- some providers or models may ignore certain settings
- `Max Steps` is especially relevant for tool-using or reasoning-heavy workflows
