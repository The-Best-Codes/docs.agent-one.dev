title: Built-in Providers
description: Enable built-in cloud providers, add API keys, and override model metadata.
---

`Built-in Providers` are the cloud services AgentOne supports out of the box.

## Enable A Provider

1. Open `Settings` -> `Providers`.
2. Find the provider under `Built-in Providers`.
3. Expand it.
4. Turn on the enable switch.
5. Enter your API key if required.
6. Save the key.

## Extra Headers

Each built-in provider also has an HTTP headers editor. This is helpful when you need provider-specific header overrides.

## Model Overrides

Built-in providers include built-in model definitions, but you can still add overrides.

Use `Add Model Override` when you want to:

- override a built-in model's metadata
- register an extra model not already shown in the built-in list

## Environment Variable Note

Some providers can also read a key from an environment variable. In the UI, AgentOne notes this with a hint such as `Using environment variable. Override below if needed.`

## Common Reasons To Use Built-In Providers

- the provider already exists in AgentOne
- you want the easiest setup path
- you do not want to manage the provider as a custom OpenAI-compatible endpoint
