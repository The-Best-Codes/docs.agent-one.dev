AgentOne is a desktop-first AI agent app built for day-to-day work. You can connect cloud providers, use local models, install extensions, manage large chat histories, and tune how the app looks and behaves.

This section documents the actual desktop app experience: what you can do, where to find it, and how the pieces fit together.

## What You Can Do in AgentOne

- Connect built-in cloud providers and local providers such as Ollama and LM Studio
- Bring your own API keys or sign in for AgentOne account features
- Search, branch, rename, export, and bulk-manage chats
- Attach files and even attach an existing chat into a new conversation
- Install built-in tools and MCP-powered extensions
- Customize streaming, notifications, titles, theme, input layout, and performance limits
- Much more!

If you are just getting started, begin with [Desktop App Getting Started](/docs/desktop-app/getting-started).
