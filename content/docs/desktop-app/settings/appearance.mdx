---

The `Appearance` settings section is split into `General Look and Feel` and `Chat Appearance`.

## General Look and Feel

You can customize:

- `Theme`
- `Primary Color`
- `Tint`
- `Tint Strength`
- `Font`
- `Roundness`
- `Text Scale`

## Chat Appearance

You can also change:

- `Markdown Highlighting`
- `Input Style`
- `Collapsed Sidebar Layout`

## Input Style

The two input styles are:

- `Docked`
- `Floating`

This changes how the composer sits at the bottom of the chat view.

## Collapsed Sidebar Layout

Choose whether the collapsed quick-action buttons use a:

- `Row`
- `Column`

## Resets

Several appearance controls include reset buttons so you can return to default behavior without resetting the entire app.
