The `Performance` settings section helps you manage large chats and heavier extension setups.

## Rendering Limits

You can set:

- `Max Message Length`
- `Max Codeblock Characters`
- `Max Tool Result Characters`

These values decide when AgentOne switches to more performance-friendly rendering behavior.

## Chat Virtualization

Use `Virtualize Chat Messages` when you want better performance in large conversations.

If enabled, you can also set `Message Count Threshold`, which controls how many messages a chat needs before virtualization turns on.

## Extension Runtime

`MCP Parallel Load Limit` controls how many MCP servers AgentOne loads at the same time.

If you use many extensions, this setting can help balance startup behavior.
