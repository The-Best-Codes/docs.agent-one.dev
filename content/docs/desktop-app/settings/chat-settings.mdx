title: Chat Settings
description: Control markdown rendering, notifications, action rows, submit behavior, streaming, and titles.
---

The `Chats` settings section controls how conversations behave.

## Chat Behavior

### Markdown Rendering

Choose whether markdown renders in:

- `All messages`
- `User messages only`
- `Assistant messages only`
- `No messages`

### Completion Notification

Choose:

- `Always`
- `When window unfocused`
- `Never`

### Message Action Row

Choose:

- `Show on hover`
- `Always show`
- `Never show`

### Submit Key

Choose:

- `Enter`
- `Ctrl + Enter`

### Other Toggles

- `Regenerate on Save`
- `Always Show Stop Button`
- `Chat Status Indicators`

## Streaming Experience

### Smooth Stream

Enables a more fluid text streaming experience.

### Experimental Throttle

Adds a configurable throttle delay to streaming.

If enabled, you can set a `Throttle Value` in milliseconds.

## Chat Titles

AgentOne can generate titles in different ways.

### Generation Method

Choose:

- `AI generated`
- `First user message`
- `First assistant message`
- `Custom phrase`

Depending on the method, you may also see:

- `Character Limit`
- `Custom Phrase`
- `Fallback Phrase`

These settings affect how new chat titles are generated and how title generation falls back when needed.
