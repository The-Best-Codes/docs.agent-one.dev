AgentOne includes built-in tools under the `Built-in extensions` card.

## Included Tools

- `Current date and time`
- `Pause`
- `Browse`
- `Search the web`
- `Edit file`
- `Create file`
- `Delete file`
- `View file`
- `Run command`
- `Spawn subagent`

## Per-Tool Controls

For each tool, you can:

- enable or disable it
- set `Require Approval`
- adjust tool-specific configuration when available

## Examples Of Tool-Specific Options

- `Current date and time`: choose whether it uses UTC
- `Pause`: set minimum and maximum duration
- `Browse`: set URL count and default max content length
- `View file`: set default max characters
- `Run command`: set default timeout
- `Search the web`: tune concurrency, max results, and max pages

## Subagent Note

The built-in `Spawn subagent` tool delegates focused work to a subagent, but subagents cannot spawn other subagents.

## Resetting Built-In Tool Settings

Use the reset button in the built-in tools area to restore default built-in tool settings.
