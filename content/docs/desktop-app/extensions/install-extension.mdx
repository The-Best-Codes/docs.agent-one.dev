---
title: Install Extensions
description: Install registry extensions and review their detected configuration before enabling them.
---

To install a registry extension:

1. Open `Settings` -> `Extensions`.
2. Search for the extension.
3. Click `Install`.
4. Review the install dialog.
5. Click `Install` again.

## What The Install Dialog Shows

The dialog can include:

- extension name
- transport type
- detected command or URL
- timeout
- approval defaults
- `Detected configuration` fields that need your input

AgentOne does not silently install registry extensions. You always get a chance to review the configuration first.

## Unsupported Extensions

Some rows may show `Unsupported` instead of `Install` if AgentOne cannot install them from the registry data.

## After Installation

Once installed, the extension appears as enabled and gains an `Advanced` button.
