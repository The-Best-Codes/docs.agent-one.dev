---
title: Add Custom Extensions
description: Add your own STDIO or HTTP MCP servers to AgentOne.
---

Custom extensions are MCP servers you add yourself instead of installing from the registry.

## Add A Custom Extension

1. Open `Settings` -> `Extensions`.
2. Click `Add Custom`.
3. Choose a `Server Type`:
   - `STDIO (Local)`
   - `HTTP (Remote)`
4. Fill in the required fields.
5. Click `Add Custom`.

## STDIO Servers

Use these when the server runs locally on your device through a command.

Typical examples start with:

- `npx`
- `uvx`
- `docker`

STDIO servers can also include environment variables.

## HTTP Servers

Use these when the MCP server lives at a remote URL.

HTTP servers can include custom headers.

## Timeout And Approval

When adding a custom extension, you can set:

- timeout in seconds
- whether it `Requires Approval` by default

## Deep-Link Pre-Fill

AgentOne can also open this dialog with fields pre-filled from a supported deep link. When that happens, the app warns you to review the details before installing.

For a broader intro to MCP, see [Using Custom MCP Servers (Extensions) in AgentOne](/docs/guides/custom-extensions).
