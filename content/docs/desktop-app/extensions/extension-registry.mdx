title: Extension Registry

---

The `Extensions` settings page includes a searchable browser for installable registry extensions.

## Search And Filter

You can:

- search by name or related terms
- show only installed extensions
- filter by connection type

Connection type filters are:

- `Runs on this device`
- `Connects online`

## What Each Row Shows

An extension row can show:

- name
- description
- version
- icon
- website link
- category badges
- install or uninstall actions
- enabled status
- load status

## Sort Order

Without a search query, AgentOne prioritizes:

- built-in extensions
- installed extensions
- everything else

## Advanced View

Installed extensions expose an `Advanced` button for deeper configuration and debugging.
