---
title: Keyboard Shortcuts
description: The built-in keyboard shortcuts currently supported by AgentOne.
---

AgentOne currently includes these app-level shortcuts:

| Action                | Shortcut |
| --------------------- | -------- |
| Open settings         | `Ctrl+,` |
| New chat              | `Ctrl+N` |
| Focus chat search     | `Ctrl+K` |
| Toggle sidebar        | `Ctrl+B` |
| Focus main chat input | `Ctrl+L` |

## Notes

- `Ctrl+K` focuses sidebar search when the sidebar is open
- if the sidebar is collapsed, `Ctrl+K` opens chat search in a dialog
- `Ctrl+L` moves focus back to the main composer
