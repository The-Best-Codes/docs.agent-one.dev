---
title: Desktop Layout
description: Learn where the main areas of the AgentOne desktop app are.
---

The desktop app has three main areas.

## Sidebar

The sidebar is where you:

- create a new chat
- search chats
- browse chat history
- open `Settings`

You can also collapse the sidebar with `Ctrl+B`.

## Main Chat Area

The center area shows:

- the current conversation
- streaming responses
- tool activity
- message actions such as copy, edit, branch, and regenerate

## Composer

The composer sits at the bottom of the chat view. It includes:

- the message input
- attachment controls
- the model selector
- the model config button
- send or stop controls

## Settings Area

When you open `Settings`, AgentOne shows a separate settings view with these sections:

- `Account`
- `Appearance`
- `Chats`
- `Extensions`
- `Performance`
- `Providers`
- `Help & Updates`

## Mobile-Sized Windows

On smaller windows, the sidebar opens as a drawer instead of staying pinned to the left.

This keeps the chat view usable even in narrower layouts.
