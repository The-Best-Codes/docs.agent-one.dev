If you have already installed AgentOne, the fastest path is:

1. Open the app.
2. Finish onboarding.
3. Sign in or continue without an account.
4. Enable at least one provider.
5. Start a chat and send your first message.

## Before You Begin

1. Install AgentOne from the [Installation Guide](/docs/installation)
2. Make sure you have either:
   - an AgentOne account, or
   - an API key for at least one provider, or
   - a local model runtime such as Ollama or LM Studio

<Callout title="No provider, no replies" type="warning">
  AgentOne can open without any providers configured, but it will not be able to
  answer messages until at least one model is available.
</Callout>
