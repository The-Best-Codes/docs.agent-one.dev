Once a provider is available, you are ready to chat.

## Start A New Chat

- Click `New Chat` in the sidebar
- Or use `Ctrl+N`

If there are no messages yet, AgentOne shows an empty-state greeting such as `What's on your mind?`, `Ask me anything.`, or `Ready when you are.`

## Pick A Model

At the bottom of the chat window, use the model selector to choose a model.

The selector groups models by provider, so you can quickly switch between providers and local runtimes.

## Write Your Message

Type in the chat box labeled with the placeholder `Ask anything...`

Depending on your settings, you can send with:

- `Enter`
- `Ctrl + Enter`

## Attach Files

You can add files in several ways:

- Click the paperclip button
- Drag files into the composer
- Paste files from the clipboard

You can also drag an existing chat from the sidebar into the composer. AgentOne converts that chat into an attached file so the current conversation can reference it.

## Stop A Response

When the model is responding, the send button changes into a stop button.

If `Always Show Stop Button` is enabled in chat settings, the stop button appears immediately after you submit a message.

## Tune The Current Chat

Next to the model selector is the model configuration button. You can adjust values such as:

- Temperature
- Top P
- Top K
- Frequency Penalty
- Presence Penalty
- Max Steps
- Max Tokens
- Seed

These settings apply to the current chat.
