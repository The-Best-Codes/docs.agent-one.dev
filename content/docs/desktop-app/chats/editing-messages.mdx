---
title: Edit Messages
description: Edit existing messages and control whether AgentOne regenerates after saving.
---

AgentOne lets you edit existing messages directly in the conversation.

## Editing A User Message

When editing a user message, you can:

- change the message text
- click `Save`
- choose whether to use `Regenerate when Saved`

If regeneration is enabled, AgentOne updates the conversation from that point forward.

## Editing An Assistant Message

Assistant messages can also be opened in the editor and saved.

## Canceling An Edit

Click `Cancel` to discard your changes.

## Default Behavior

The default for regeneration-after-save is controlled by `Settings` -> `Chats` -> `Regenerate on Save`.
