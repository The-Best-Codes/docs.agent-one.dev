The sidebar is the main navigation area for your conversations.

## What You Can Do From The Sidebar

- click `New Chat`
- browse recent chats
- search chats
- open chat actions from the `...` menu
- open `Settings`

## Collapsing The Sidebar

Use `Ctrl+B` to toggle the sidebar.

When collapsed, AgentOne still shows quick buttons for:

- open or close sidebar
- `Search chats`
- `New chat`

You can choose whether those collapsed buttons appear in a `Row` or `Column` layout in `Settings` -> `Appearance` -> `Collapsed Sidebar Layout`.

## Chat List Details

Each row can show:

- the chat title
- a status indicator
- a branch icon for branched chats
- a search snippet when you are viewing content search results

## Per-Chat Menu

Open the `...` menu on a chat to access:

- `Change Title`
- `Export Chat`
- `Delete Chat`
- `Select Chat`

You can also right-click a chat to open the same actions.

## Selection Mode

Selection mode lets you manage multiple chats at once.

You can enter it by:

- choosing `Select Chat` from a chat menu
- Shift-clicking a chat

While in selection mode, you can:

- `Select All`
- `Deselect All`
- bulk export
- bulk delete
