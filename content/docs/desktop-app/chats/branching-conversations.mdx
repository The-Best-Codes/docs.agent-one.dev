---
title: Branch Conversations
description: Create a new chat branch from an existing message.
---

Branching lets you fork a conversation from a specific point instead of continuing the original thread.

## How To Branch

1. Open the message action row for a message.
2. Click `Branch conversation`.

AgentOne creates a new chat using that message as the branching point.

## Why Branching Is Useful

- explore a different idea without disturbing the original chat
- test another prompt direction
- compare two solutions from the same earlier context

Branched chats show a branch icon in the sidebar so they are easy to spot later.
