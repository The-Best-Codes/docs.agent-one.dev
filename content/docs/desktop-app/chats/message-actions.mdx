---
title: Message Actions
description: Use copy, edit, branch, and regenerate actions on chat messages.
---

Each message can show an action row depending on your `Message Action Row` setting.

The available actions include:

- `Copy message`
- `Branch conversation`
- `Regenerate response`
- `Edit message`

## Copy Message

Use this when you want the message contents in your clipboard.

## Regenerate Response

Use this on assistant output when you want a fresh answer from the current conversation state.

## Edit Message

When you edit a user message, AgentOne lets you save the change and optionally regenerate afterward.

The edit menu includes `Regenerate when Saved`.

Whether that option is enabled by default is controlled by `Settings` -> `Chats` -> `Regenerate on Save`.

## Visibility Of The Action Row

In `Settings` -> `Chats` -> `Message Action Row`, you can choose:

- `Show on hover`
- `Always show`
- `Never show`

If you choose `Never show`, the actions are hidden from the normal row even though the underlying features still exist where the UI exposes them elsewhere.
