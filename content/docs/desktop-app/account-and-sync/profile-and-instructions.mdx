title: Profile and Instructions
description: Set your name and add global AI instructions for AgentOne.
---

The `Profile & Instructions` card lets you personalize how AgentOne addresses you and responds.

## Your Name

The `Your Name` field controls the name AgentOne uses when referring to you.

## AI Instructions

Use `AI Instructions` to add global guidance that AgentOne appends to its system prompt.

Examples:

- ask for concise answers
- prefer British English
- request a specific writing style
- tell AgentOne how to format code explanations

## Character Limit

The instructions field has a character limit and shows a live character count in the UI.

## When To Use This

Use account-level AI instructions for stable preferences that should apply broadly, not for one-off requests that belong inside a single chat.
