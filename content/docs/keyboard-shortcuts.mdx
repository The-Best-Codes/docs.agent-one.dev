AgentOne includes a keyboard shortcut system to help you navigate and interact with the app faster.

## Message Submission

The key used to send messages can be configured in **Settings → Chats**:

| Setting        | Behavior                                      |
| -------------- | --------------------------------------------- |
| **Enter**      | Press Enter to send, Shift+Enter for new line |
| **Ctrl+Enter** | Press Ctrl+Enter to send, Enter for new line  |
