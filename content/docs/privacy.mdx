AgentOne is designed to be private by default.

## Core Principles

- **Your data stays on your device** — chats, settings, and API keys are stored locally
- **Explicit access only** — AgentOne only accesses tools and information you explicitly connect
- **Encrypted sync** — when cross-device sync is enabled, API keys are encrypted before leaving your device
- **Desktop-native** — AgentOne runs as a native desktop app, not a browser tab, giving you full control over your data
