---
title: "Credits and plans"
description: "Check AgentOne usage and distinguish it from third-party provider costs."
---

AgentOne credits apply to requests through the **AgentOne** provider. The Free plan includes a monthly allowance; paid plans provide higher capacity. Check the [current pricing page](https://www.agent-one.dev/pricing) for allowances, prices, and availability.

## Check usage

Open **Configure AgentOne → Account** to see your plan, usage period, and available credit information. You can also open **Billing** in the [website dashboard](https://www.agent-one.dev/dashboard/billing).

An agent task can make multiple requests while it uses tools, retries, generates a title, or delegates to a subagent. A credit isn't necessarily equivalent to one chat message. Monitor the account's actual usage rather than estimating solely from the message count.

If usage is missing or differs between the app and dashboard, verify the account and current period, refresh the relevant view, and [contact support](https://www.agent-one.dev/discord) with the discrepancy. Don't assume a missing usage display means unlimited access.

## Other connections have their own costs

| Connection                       | Where usage is managed                                                            |
| -------------------------------- | --------------------------------------------------------------------------------- |
| AgentOne's Default model         | AgentOne account and credits                                                      |
| Your own external model provider | That provider's API account                                                       |
| Local inference                  | Your device and the local server; cloud routes still follow their service's rules |
| Text-to-speech                   | The chosen speech provider                                                        |
| Third-party extension            | Its service's account and pricing, when applicable                                |

## Change a subscription

Use the dashboard's **Billing** page to review plans or open subscription management. Read the current checkout or billing portal details before confirming a change, including billing period and renewal terms.

Features marked **beta** can have account-specific availability. A pricing-page mention of chat sync, encrypted key sync, or cloud runs doesn't mean the desktop settings-sync switch provides those features in every account. The desktop scheduled agents described here run on your device. See [data and sync](/docs/account/data-and-sync) for current boundaries.

## Credits are exhausted

Check the current allowance and period in Billing. You can review a higher plan or use [your own provider](/docs/models/providers) or [a local model](/docs/models/ollama), subject to that connection's requirements. Repeatedly retrying the same blocked request won't change the account limit.
