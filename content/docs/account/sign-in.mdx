## Connect the desktop app

Open **Configure AgentOne → Account** and use its sign-in option. Complete the browser sign-in, then return to AgentOne when prompted. Check that the desktop Account tab shows the intended account.

The website offers email/password and supported Google, GitHub, and Discord sign-in options. Use the method associated with your account. Creating a separate account by mistake can make your existing plan or settings appear to be missing.

## The browser doesn't return to the app

Keep the installed AgentOne app available and allow the normal app-opening prompt for the sign-in you initiated. If the browser can't open AgentOne, check installation and the `agent-one://` handler. See [deep links](/docs/settings/deep-links), especially for standalone Linux installations.

A working website session doesn't necessarily mean the desktop app finished connecting. Verify the account in the app before testing the Default model.

## Your own providers

External provider keys and local models are configured under **Providers**. Signing in to AgentOne doesn't automatically sign you in to those services or enable their API billing.

## Sign out or review sessions

Use the desktop account controls to sign out of the app. The website's **Sessions** page lets you inspect and revoke website account sessions. Review the session before revoking it so you don't accidentally interrupt the device you're using.

For password recovery, email changes, and linked sign-in methods, use the website's account settings. See [the dashboard guide](/docs/account/dashboard).
