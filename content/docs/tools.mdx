AgentOne includes several built-in tools that the agent can use during task execution. Each tool can be enabled or disabled and has a configurable "requires approval" toggle in **Settings → Extensions**.

## Date & Time

**ID:** `dateTime`

Returns the current date and time.

| Setting           | Description                                  |
| ----------------- | -------------------------------------------- |
| Approval required | Require user approval before use             |
| UTC mode          | Return time in UTC instead of local timezone |

## Web Search

**ID:** `webSearch`

Searches the web and returns results.

| Setting             | Description                                  |
| ------------------- | -------------------------------------------- |
| Approval required   | Require user approval before use             |
| Max concurrent      | Maximum number of concurrent search requests |
| Default max results | Default number of results to return          |
| Default max pages   | Default number of pages to fetch             |

## URL Content

**ID:** `getUrlContent`

Fetches and reads the content of a web page.

| Setting            | Description                             |
| ------------------ | --------------------------------------- |
| Approval required  | Require user approval before use        |
| Max URLs           | Maximum number of URLs to fetch at once |
| Default max length | Default maximum content length          |

## Wait

**ID:** `waitNumberMilliseconds`

Pauses agent execution for a specified duration.

| Setting           | Description                      |
| ----------------- | -------------------------------- |
| Approval required | Require user approval before use |
| Min milliseconds  | Minimum wait duration            |
| Max milliseconds  | Maximum wait duration            |

<Callout type="info">
  The Wait tool is **disabled by default**. Enable it in Settings → Extensions
  if your workflows need timed delays.
</Callout>
