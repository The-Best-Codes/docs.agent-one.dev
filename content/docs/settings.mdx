AgentOne's settings are organized into the following sections: **Account**, **Appearance**, **Chats**, **Extensions**, **Performance**, **Providers**, and **Help & Updates**.

## Appearance

| Setting     | Options                                                 |
| ----------- | ------------------------------------------------------- |
| Theme       | Light, Dark, System                                     |
| Color theme | Default, Red, Blue, Yellow, Green, Orange, Rose, Violet |
| Roundness   | Adjustable border radius                                |
| Font        | Default, System, Mono                                   |
| Text scale  | Adjustable text size                                    |

## Chats

| Setting            | Options                                |
| ------------------ | -------------------------------------- |
| Markdown rendering | Toggle rendered markdown in messages   |
| Submit key         | Enter or Ctrl+Enter                    |
| Input style        | Docked or Floating                     |
| Max message length | Character limit for messages           |
| Title generation   | AI-generated, First message, or Custom |

## Performance

| Setting          | Description                                 |
| ---------------- | ------------------------------------------- |
| Throttle         | Reduce resource usage during streaming      |
| Smooth streaming | Animate token rendering for smoother output |

## Extensions

Manage built-in tools and MCP servers. See [Built-in Tools](/docs/tools) and [MCP Servers](/docs/mcp) for details.

## Providers

Configure API keys and model providers. See [AI Providers](/docs/providers) for details.
